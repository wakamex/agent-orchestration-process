Agent Orchestration Process (AOP) 0.2.0 changes how run records and costs are stored, enforces `--no-web` at the network level, and adds options for minimally prompted Claude runs. Runs, resumes, and cleanup keep working as before after one upgrade step.

## Upgrading from 0.1.x

- Run `aop migrate-results` once. AOP now reads only current run records and stops with that instruction when it finds an older `result.json` or `request.json`. The command converts every older record it finds, keeps each original beside it as `result.pre-v3.json` or `request.pre-v3.json`, and notes in the rewritten record what it changed. `aop migrate-results --dry-run` shows the counts first. ([`d379eb0`](https://github.com/wakamex/agent-orchestration-process/commit/d379eb0803c76abe3e9df2ccea47104205e6baf3), [`8f8d5e5`](https://github.com/wakamex/agent-orchestration-process/commit/8f8d5e56c0097c09a1254b97932ac4e43c4f04ff))
- Results now carry `usage_schema: "aop-token-usage-v3"`. Every result counts only its own run's tokens, so totals can be summed across runs and resumes. Earlier Agy results that resumed a conversation repeated that conversation's running total; the migration recomputes them from each run's own events. Tools that read `result.json` directly should accept v3. ([`303014d`](https://github.com/wakamex/agent-orchestration-process/commit/303014d9e52043b9ce82941c1880b81c5aab027d))
- AOP no longer picks a default model of its own for Grok, OpenCode, or Hermes. It uses the harness's own default and records which model ran. OpenCode runs without `--model` need a model configured in OpenCode. ([`4d11f2b`](https://github.com/wakamex/agent-orchestration-process/commit/4d11f2b388553ee0210e4437748c04dc5bb9793d))
- AOP now needs the [model-prices](https://pypi.org/project/model-prices/) package, which installs with it.

## Costs at the rates in effect when each run happened

Calculated costs come from model-prices, which keeps price history with sourced corrections and DeepSeek's peak and off-peak hours. Each request is priced at the time it ran, each cost records which price data priced it, and AOP downloads newly published prices daily without needing a new release. ([`8e4b7de`](https://github.com/wakamex/agent-orchestration-process/commit/8e4b7de70ba9e443e54b52809a4bf0d692801d6f), [`e3fa55e`](https://github.com/wakamex/agent-orchestration-process/commit/e3fa55eca703f6d59f5162414a275036fe884aa8), [`c55b073`](https://github.com/wakamex/agent-orchestration-process/commit/c55b0733878037cce6dce983af03ee4c7d417192))

## `--no-web` enforced at the network level

In the `edit`, `review`, and `sealed` profiles, a `--no-web` run gets its own network with no outside access except through a proxy that allows only the harness's inference and login endpoints. Every connection attempt is logged in the run's `network.jsonl`. `--allow-url` adds an explicit endpoint, such as a local request recorder. `--no-web` now also works for DeepSeek Harness and Devin, which lose their web search and shell tools, because their search runs on the provider's servers. ([`42da72b`](https://github.com/wakamex/agent-orchestration-process/commit/42da72b6601e44f532fa336aa7c139117f4c777d), [`e93cfb9`](https://github.com/wakamex/agent-orchestration-process/commit/e93cfb9c0a9181537988d20d3935a9d5bcc32f43))

## Claude run options

- `--system-prompt` or `--system-prompt-file` replaces Claude's base system prompt, and `--tools` sets its exact tool list. ([`e9c00c5`](https://github.com/wakamex/agent-orchestration-process/commit/e9c00c5bf57ea4de32266129c6cda7dbd9ac6d5e))
- `--provider-base-url` sends Claude's inference requests to another URL, such as a local recorder, and works with the Claude login. AOP refuses a run when `ANTHROPIC_BASE_URL` is set in the environment without this option, instead of silently ignoring it. ([`6d406e9`](https://github.com/wakamex/agent-orchestration-process/commit/6d406e93800f9820f019247fcdfe28e8f77704ed))
- `--thinking-display summarized` returns Anthropic's official summaries of the model's thinking in the run's events. ([`0d5a1bf`](https://github.com/wakamex/agent-orchestration-process/commit/0d5a1bff998ee86a93fe85f6660debe8e1dcfcf0))

All three are recorded in `request.json` and reused when the run is resumed.

## Sealed runs

- Sealed Claude runs no longer receive the claude.ai account's connectors or synced skills, which arrived with the login. ([`0ef9aaa`](https://github.com/wakamex/agent-orchestration-process/commit/0ef9aaaa12d95f97f93c0b035ab6a1f7ac290b76))
- `--writable-workspace` lets a sealed run write its private, initially empty `/workspace`, and resumes keep the files. ([`0ef9aaa`](https://github.com/wakamex/agent-orchestration-process/commit/0ef9aaaa12d95f97f93c0b035ab6a1f7ac290b76))
- Resuming and cleaning up a sealed run started inside a Git repository now finds the run. ([`0ef9aaa`](https://github.com/wakamex/agent-orchestration-process/commit/0ef9aaaa12d95f97f93c0b035ab6a1f7ac290b76))
- `aop cleanup` removes a sealed run's runtime files even when `AOP_SEALED_RUNTIME_ROOT` differs from the original setting, and lists what it removed. ([`66091c9`](https://github.com/wakamex/agent-orchestration-process/commit/66091c95ab82c6f38abb1045a59a53865f9cbf11))
- Sealed and `--no-web` Codex runs no longer download Codex's plugin marketplace, about 100 MB per run. ([`3315c44`](https://github.com/wakamex/agent-orchestration-process/commit/3315c446112512a42d56fff1b072785a990e9390))
