Claude runs can now send the prompt as separate blocks and mark one of them for Anthropic's prompt caching, so runs that repeat a long prompt prefix read it from cache instead of paying for it each time. Pass `--prompt-parts PATH` to `aop run` or `aop resume`; [Harness adapters](https://github.com/wakamex/agent-orchestration-process/blob/v0.2.1/docs/harnesses.md) describes the file format and the one-mark limit. Other harnesses reject the option.

Sandboxed runs can now start programs whose libraries live in folders registered with the system's dynamic linker, such as ffmpeg on Fedora, which needs PipeWire's `libjack.so.0`. Before, these failed with "cannot open shared object file". The sandbox also mounts `/sbin` now, so programs that call tools there, such as Ubuntu's `ldconfig` wrapper, no longer fail with exit status 127.
