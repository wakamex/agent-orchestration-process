A whole project folder now works as one `--input`. AOP checks every input before it creates any run state, and `--dry-run` runs the same check, so a dry run that passes no longer fails later on an input. The dry run also prints each input's file count, size, excluded paths and symlinks.

- Symlinks inside an input folder that point elsewhere in the same folder, such as `CLAUDE.md -> AGENTS.md`, are copied as their targets. A symlink that points outside the input still fails the run, with a message naming `--skip-external-links`, which leaves such links out instead.
- `--input-exclude GLOB`, which can be repeated, leaves matching paths out of every input folder, for example `--input-exclude 'runs/*/net-*.pt'`.
- AOP's own `.aop` state is always left out of an input that contains it. Before, using the folder AOP runs from as an input copied the snapshot into itself until the path grew too long.
- Each input's followed and skipped links and excluded paths are recorded in `input-manifest.json`, and resumes apply the same options again.
- While a harness runs, `events.jsonl` and `stderr.log` in the run directory grow as output arrives, so `tail -f` shows progress. Codex and ZCode still write these files when the run ends.
- When `agy` is not on `PATH`, the error now names the searched `PATH` and the `AOP_AGY_BIN` setting.
