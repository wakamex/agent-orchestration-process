Documentation now lives at [agentorchestrationprocess.com](https://agentorchestrationprocess.com/), with a new home page, a page on running agents unattended, and a glossary. No migration is needed from 0.3.x.

## Running harnesses

- A run that reaches its `--timeout` now sends the stop signal to the harness itself, which gets five seconds to save its session before the sandbox is stopped. Before, the sandbox was killed at once and no harness ever received the signal. The sandbox's own process 1 now collects orphaned processes, which also removes Hermes's warning about running as process 1.
- `--workdir DIR` runs a `host` harness in `DIR` itself, Git or not, instead of a task worktree. `--native-state` lets Claude use your own home, settings, memory and sessions. Together they make a run behave like starting `claude` in that directory.
- `aop resume` and `aop cleanup` find a run from any directory, through the run's archived result or the registered state folders.
- Claude runs are seeded from `CLAUDE_CONFIG_DIR` when it is set, so a run started under a second account uses that account's login.
- The instructions AOP adds for declared artifacts now ask the agent to write them with its file-writing tool, not a shell command, after an agent's shell-quoted write turned "$10M" into "0M".

## Results

- Results have a `refusal` field: null, or the refusal's category, explanation and models when the provider refused the input. A caller can tell a refusal, which never succeeds on retry, from an outage or quota limit without matching error text.
- A resumed Hermes 0.22 run that repeats its previous answer word for word now keeps that answer instead of reporting none.
