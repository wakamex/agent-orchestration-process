A run is no longer reported as succeeded when the model never answered. Runs whose final answer is empty or whitespace, unless the run declared `--artifact` files, now fail with "the harness returned an empty answer", and runs whose final answer is a tool call the model wrote as text instead of making it, as DeepSeek models do through some harnesses, fail with "the model wrote a tool call as text instead of making it". Callers that treated those runs as successes will now see `status: failed` and exit code 1, and a caller that retries failures will retry them.

Hermes runs no longer fail in sandboxed profiles when the Hermes home's `tools` folder is a symlink. New opt-in tests, `AOP_TEST_HERMES_BIN` and `AOP_TEST_AGY_BIN`, check installed Hermes and Antigravity through AOP without spending quota; see [CONTRIBUTING.md](https://github.com/wakamex/agent-orchestration-process/blob/v0.4.1/CONTRIBUTING.md).
