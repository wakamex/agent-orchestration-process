`aop cleanup --all` cleans every finished task in a project at once, and cleanup no longer loses task commits that were never merged.

- `aop cleanup --all` removes every task worktree and sealed run's runtime state in the current project's AOP state, including worktrees left without a run record. Tasks that are still running are skipped and reported, and the command then exits 1. `--dry-run` lists what would be removed. Run records, results, logs, and artifacts are kept, as with single-run cleanup ([`6c031a4`](https://github.com/wakamex/agent-orchestration-process/commit/6c031a465a1e27e3ffb5a26cad5f498262dda633)).
- Task worktrees are detached, so removing one used to drop any commit no branch or tag contained. `aop cleanup` and `aop worktree remove` now keep such a commit at `refs/aop-archive/<task>/<commit>` and print that ref to stderr. Integrated work is already on main and gets no ref ([`6c031a4`](https://github.com/wakamex/agent-orchestration-process/commit/6c031a465a1e27e3ffb5a26cad5f498262dda633)).
