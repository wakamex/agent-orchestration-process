AOP 0.6.0 adds [Muse Code](https://dev.meta.ai/), Meta's coding agent, as its eleventh harness, counts every model call a Muse run makes, and makes long Devin runs survive Devin's free-model rate limit.

## Muse Code

- `aop run --agent muse` runs Muse Code headless with the login `muse login` saved, in every profile, and `aop resume` continues the same Muse session. Each task gets a private copy of Muse's config with an empty home, so Muse does not read other agents' instructions from `~/.claude`, `~/.codex`, or `~/.agents`; sealed runs keep only the login and the provider, model, contributor-mode, telemetry, and reminder settings. Set `AOP_MUSE_BIN` when `muse` on `PATH` is not the Muse executable ([`1b6b670`](https://github.com/wakamex/agent-orchestration-process/commit/1b6b6705ba2ad686f4dd3e3e1d00b696910a225d)).
- `--no-web` works in the sandboxed profiles. Muse's web search runs on Meta's servers through its inference host, so a `--no-web` run also loses its web tools and its shell, and keeps its file tools ([`bf75c67`](https://github.com/wakamex/agent-orchestration-process/commit/bf75c673a3504b4558ae6cf644eb7ce4f867b3d3)).
- Usage covers every model call: `muse exec --json` reports only the main agent, so AOP adds Muse's goal, verify, and skill reminder calls from the session log in the task's private state, after checking that the log's main-agent calls match what Muse reported. A mismatch or a missing log keeps Muse's figure and marks accounting `partial` ([`98a5548`](https://github.com/wakamex/agent-orchestration-process/commit/98a5548be1315df0237c97328e992a692b9ed9f9)). One invocation can run several turns, and usage covers all of them ([`1e42f1c`](https://github.com/wakamex/agent-orchestration-process/commit/1e42f1c0419faebc1181f03c69780655ebf4278a)).
- Costs are API-equivalent at Meta's rates: main calls at the run's model and reminder calls at `muse-spark-1.3` ([`7fc5b27`](https://github.com/wakamex/agent-orchestration-process/commit/7fc5b2785ca4997addf91f8e53d3fb1968a0db2b)). Muse Wonder Full has no per-token price, so its calls are priced at the stand-in [model-prices](https://pypi.org/project/model-prices/) 0.0.5 names for it, Muse Wonder's rates, and the cost's new `estimated_from` field says so. AOP now requires model-prices 0.0.5 ([`4f89cf5`](https://github.com/wakamex/agent-orchestration-process/commit/4f89cf59f9bdf7d49b4fdf82348a291d9a843110)).
- `--reminders all|none|goal,verify,skill` chooses which reminder agents a Muse run uses, and `AOP_MUSE_REMINDERS` sets a default with per-profile overrides, such as `goal,verify sealed=none`. Without either, Muse's own settings decide ([`7dc165f`](https://github.com/wakamex/agent-orchestration-process/commit/7dc165f264d9ef78b10fcc15b5ad7bd7a3b8ca40)).

## Devin

- A Devin run that stops at a usage limit, such as the free-model rate limit, now waits for the reset time Devin's error names and continues the same session, up to 10 times and within `--timeout`. A limit that resets after the deadline fails with the session ID, so `aop resume` can continue it ([`3d9e466`](https://github.com/wakamex/agent-orchestration-process/commit/3d9e466d35506c79b05bdf1f30c67d80e25e4f56)).
- Devin runs that finished their work are no longer reported as failed: Devin records the prompt without its trailing newline, which AOP now accepts ([`3d9e466`](https://github.com/wakamex/agent-orchestration-process/commit/3d9e466d35506c79b05bdf1f30c67d80e25e4f56)).
- A Devin prompt that starts with `/` is refused before the run starts, because Devin runs it as a slash command instead of sending it to the model ([`bbad49c`](https://github.com/wakamex/agent-orchestration-process/commit/bbad49c271e20695c97874c1f204be0e756656a3)).
