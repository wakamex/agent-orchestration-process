AOP 0.6.2 lets tools run inside host Claude runs find their usual state, and documents how a run executes long commands.

- Host Claude runs keep your own `HOME`. Claude now reaches AOP's private copy of its configuration through `CLAUDE_CONFIG_DIR` instead of a replaced `HOME`, so tools the agent runs, such as rootless podman, use their normal state rather than failing inside the run's state directory. A host task's existing private Claude state carries over on its next run. Sandboxed profiles are unchanged ([`b6fc9b9`](https://github.com/wakamex/agent-orchestration-process/commit/b6fc9b901f184168db8667ff4804e982780b2e55)).
- [Running unattended](https://github.com/wakamex/agent-orchestration-process/blob/main/docs/unattended.md) now says how to run a long check such as a full build: with the harness's own shell tool, in the foreground or that tool's background mode, never as a service or detached process that outlives the run. It gives a sentence to put in briefs, and a test checks that the sandboxed profiles cannot reach the user's service manager ([`b09f6fe`](https://github.com/wakamex/agent-orchestration-process/commit/b09f6fe51ad7b2dadfa8fc3180c1f6057d025465)).
