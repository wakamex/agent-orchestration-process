This release makes run records more complete and more accurate: runs that are interrupted or killed still get a result, Cursor and Devin runs are priced, and Devin token counts now come from the session database Devin keeps for each task. After upgrading, run `aop migrate-results` once to bring existing records up to date.

## Highlights

- A run stopped by SIGTERM, SIGHUP or SIGINT now records and archives a result with the usage seen so far, marked `interrupted`, and exits with 128 plus the signal number. AOP also prints `aop: run_id=<id> started task=<task>` to stderr when a run starts. ([`b6bf114`](https://github.com/wakamex/agent-orchestration-process/commit/b6bf11452897af56464f944efec1abee8489c18e))
- Cursor and Devin runs are priced at the model's API rates when they finish. `aop migrate-results` prices older results that have usage but no cost, and rebuilds a result from `events.jsonl` for runs whose AOP process was killed outright. A resumed Devin session now keeps the run's model. ([`464799b`](https://github.com/wakamex/agent-orchestration-process/commit/464799b44d44532295ec998048ccc665be604271))
- Devin usage is the sum of the model calls its session database recorded during the run. Devin's trajectory export misses steps before a context compaction and is missing entirely when a turn fails, so earlier Devin results could undercount or show zero tokens and $0. The migration recomputes them from the database while the task's private state still exists, and marks zero-usage results it cannot check as unknown. ([`04f3182`](https://github.com/wakamex/agent-orchestration-process/commit/04f3182400d2f33d4712df3e4738d02d97d03e91))
- An OpenCode run that logs a provider error, such as a spent usage quota, and then goes silent for 30 seconds is stopped and fails with that error and its reset time, instead of idling until its deadline. OpenCode's log lines for a run are now in its `stderr.log`. ([`f54f286`](https://github.com/wakamex/agent-orchestration-process/commit/f54f2864e6acb59d510b18dce062113d50fcba29))
- `aop migrate-results --help` says that every invocation also migrates the results archive and compacts the state-roots registry, whichever run directories are named. ([`dc60e10`](https://github.com/wakamex/agent-orchestration-process/commit/dc60e10b892dd6b7b5fb000eff428a16e9d02e65))
