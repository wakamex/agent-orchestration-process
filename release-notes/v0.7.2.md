This release corrects Claude token counts and makes sandboxed Claude runs behave more like runs started by hand. After upgrading, run `aop migrate-results` once so existing Claude results get the corrected counts.

## Highlights

- A Claude run of several turns now records every turn's tokens. Each turn ends in its own result event with that turn's usage alone, and AOP used to keep only the last one, so token counts could be a fraction of the run's real use while the cost was already right. ([`d02cea1`](https://github.com/wakamex/agent-orchestration-process/commit/d02cea135bdbf705a778207a8fe97c3c7dab266d))
- With prompt caching off, Claude Code 2.1.330's summary counts a run's input twice, in its tokens and its cost. AOP now counts that input once, from the run's own calls, and prices the run from model-prices. ([`5778b0c`](https://github.com/wakamex/agent-orchestration-process/commit/5778b0c15c2264e5adf9929d1fde5e61e8574811))
- `DISABLE_PROMPT_CACHING`, its per-model variants and `FORCE_PROMPT_CACHING_5M` now reach Claude in the `edit`, `review` and `sealed` profiles, so a single call whose prompt is never read again can skip the cache write. ([`444c1f2`](https://github.com/wakamex/agent-orchestration-process/commit/444c1f279664d56471f7741a7c1c4c314ebecb83))
- `--claude-settings JSON_OR_FILE` gives one Claude run its own Claude Code settings on every profile, without changing your settings files, and resumes keep them. ([`6bfacf5`](https://github.com/wakamex/agent-orchestration-process/commit/6bfacf5bff7e123351d991b37d5535a960a1c1af))
- Sandboxed Claude runs no longer carry your hooks and status line, whose commands usually live outside the sandbox. A prompt that a hook blocks now fails the run instead of reporting success. ([`62c6f63`](https://github.com/wakamex/agent-orchestration-process/commit/62c6f63f1682a5d4b60d412c487169d4466185e8))
- In the sandboxed profiles, `/tmp` lives in the task's scratch directory, so files built there are still present when the task is resumed. `aop cleanup` removes it with the scratch directory. ([`6a85878`](https://github.com/wakamex/agent-orchestration-process/commit/6a85878c581238d40fc7fae1a86bc2371b03a73e))
